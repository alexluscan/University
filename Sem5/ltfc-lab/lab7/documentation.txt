1. Introduction
---------------
This project implements:

  - Requirement 1: LL(1) parser for the seminar grammar
        S → Bb | Cd
        B → aB | ε
        C → cC | ε

  - Requirement 2: LL(1) parser for the mini DSL grammar
    using the tokens provided in the PIF file generated by the lexical scanner.

The parser outputs:
    a) production sequence
    b) leftmost derivation
    c) parse tree in father–sibling representation

This satisfies the maximum grade requirements.


2. Technologies used
--------------------
- C programming language
- LL(1) parsing theory from course notes
- FIRST and FOLLOW computation
- LL(1) table construction
- Stack-based parsing (α, β, π configuration model)
- PIF file input (token name + ST index)


3. Grammar used for Requirement 2 (mini DSL)
--------------------------------------------
Start symbol: PROGRAM

1: PROGRAM   -> STMT_LIST
2: STMT_LIST -> STMT STMT_LIST
3: STMT_LIST -> ε
4: STMT      -> LOAD STRING INTO ID
5: STMT      -> SAVE ID TO STRING
6: STMT      -> PRINT ID
7: STMT      -> DELETE ID
8: STMT      -> APPEND STRING TO ID
9: STMT      -> IF COND THEN STMT_LIST ENDIF
10: COND     -> ID COMP STRING
11: COMP     -> EQUALS
12: COMP     -> CONTAINS
13: COMP     -> STARTSWITH
14: COMP     -> ENDSWITH

Terminals correspond exactly to the tokens in the lexer.


4. Input Format for Requirement 2
---------------------------------
The parser reads the PIF file generated by the scanner.

Expected PIF format (one token per line):

    TOKEN_NAME  ST_INDEX

Examples:
    LOAD -
    STRING 0
    INTO -
    ID 1

Only the token name is used for LL(1) parsing;
the ST index is ignored.


5. Running the parser
---------------------
Compile:

    gcc ll1_parser.c -o parser

Run:

    ./parser

Choose mode 2 for the mini DSL:

    2

Place a correct PIF file in the same folder named:

    PIF.txt


6. Output Description
---------------------
The parser prints:

• FIRST sets  
• FOLLOW sets  
• LL(1) parsing table  

Then parsing begins. For Requirement 2, all three required outputs are shown:

a) Production sequence
   Example:
        1 2 4 6 3 ...

b) Leftmost derivation
   Each step prints the current sentential form.

c) Parse tree (father–sibling table)
   Columns:
        Index | Symbol | Parent | Sibling

This structure can be easily converted into a
tree visualization (Graphviz) if needed.


7. Error handling
-----------------
If a token in the PIF does not exist in the grammar,
the parser reports:

    ERROR: Unknown token 'XYZ' in PIF.txt

If the LL(1) table entry is empty, the parser reports:

    Syntax error: unexpected symbol 'LOAD'
